## 🚀 Featured Projects

### 📈 [FNP Sales Analysis Dashboard](https://github.com/Ishitakharde/FNP_Sales_analysis)
An Excel-based sales analysis project that explores business performance through a dashboard.

- Summarizes revenue and other key performance indicators
- Compares monthly and occasion-wise revenue
- Explores city, product-category, and top-product performance
- Uses PivotTables, PivotCharts, and an occasion slicer

**Tools:** Microsoft Excel, PivotTables, PivotCharts, Dashboarding

### 🧾 DocuShield — AI-Based Document Forgery Detection
A document verification project designed to classify documents as **Authentic**, **Suspicious**, or **Needs Review** using computer vision and AI-assisted analysis.

**Tools:** Python, OpenCV, YOLOv8, Gemini API  


### 💬 [Resume Assistant](https://github.com/Ishitakharde/resume_assistant)
A Python chatbot that helps users work with resumes and job descriptions, with a Flask backend and SQLite session storage.

**Tools:** Python, Flask, SQLite, Gemini API
